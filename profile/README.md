## How we work

- **One team, from interface to infrastructure.** Web, mobile and API live in one monorepo and share types, UI and CI.
- **AI from day one.** Model calls, agents and retrieval are part of the product, not bolted on.
- **Agents write the code. We decide what to build and review every change.** We build with Claude Code, Codex, opencode and Antigravity, and don't tie any product to one provider.
- **We keep it running.** Every product moves from dev to staging to production, and we stay on it.
